# 比对报告差异居中导航

把 Beyond Compare 导出的 HTML 比对报告重排成**左右双栏对照视图**，两侧各自横向滚动且联动，并支持上一个/下一个差异跳转。

## 为什么不用原表格

原报告的布局是「单张大表格 + 内容不换行」，长代码行会把表格撑到上万像素宽（实测某报告总宽 16442px，左右两列各 8171px）。在普通显示器上永远只能看到一侧，必须整页横向拖动。

扩展把表格数据抽出来重新排版：左右各占一半视口宽度，各自横向滚动、滚动位置联动，因此**两侧始终同时可见**。

## 功能

- **左右双栏**：左栏红标、右栏蓝标，标题栏显示两边文件名；中间分隔条可拖动调整比例。
- **滚动联动**：滚轮或拖动任一侧，另一侧横向与纵向同步，逐行始终对齐。
- **差异识别**：读取报告行样式（`TextItemSame` / `TextItemSigMod` / `TextItemInsigMod` / `TextItem*Add` / `TextItem*Del`）与中间 `+`、`+-` 标记判断差异。
- **差异块合并**：连续差异行合并为一处「差异块」，一次跳转覆盖整段修改。
- **跳转定位**：`◀`/`▶` 或 `Alt+↑`/`Alt+↓` 循环跳转，`Alt+Home` 回第一处；整块垂直居中，超过视口 80% 时贴顶。
- **当前差异高亮**：整块一个连续外框（首行上边、末行下边、左右各一条）+ 浅黄底色，不逐行套框。
- **仅看差异**：折叠连续 3 行以上的相同内容为「⋯ 已折叠 N 行」占位条，左右两侧同步折叠，状态存 `localStorage`。
- **双击放大对照**：双击任意差异行（或点 `⤢`）弹出上下结构对话框，长行可横向滚动、两侧联动。

## 安装

1. 打开 Chrome：`chrome://extensions/`
2. 打开右上角「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择本目录 `extensions/diff-center-nav`。
4. 打开比对报告 HTML 即可：

   - 用 `chrome://extensions/` → 该扩展「详情」→ 打开「允许访问文件网址」，刷新报告页后自动生效。
   - 未开启文件访问权限时，直接点击工具栏的扩展图标即可手动注入当前标签页。

## 使用

| 操作 | 方式 |
| --- | --- |
| 下一个差异 | `▶` 或 `Alt+↓` |
| 上一个差异 | `◀` 或 `Alt+↑` |
| 第一处差异 | `Alt+Home` |
| 仅看差异 | 「仅看差异」按钮，再次点击取消 |
| 放大对照当前差异 | 双击任意差异行，或点 `⤢` |
| 调整左右宽度 | 拖动中间分隔条 |
| 收起工具条 | `–` 收成「差异 n/m」胶囊，点击恢复 |

对话框内按 `Esc` 关闭，`Alt+↑`/`Alt+↓` 可直接切换差异。

## 适配范围

默认在 `file:///*` 与 `http://localhost/*` 下自动生效。若报告放在内网服务器或其他域名，在 `manifest.json` 的 `content_scripts[0].matches` 中追加规则；临时使用可直接点扩展图标注入。

只对同时满足以下条件的表格生效，普通网页不受影响：

- 表格带 `class="fc"`
- 至少 3 行带 `Section*` / `Subsection*` 类名
- 每行 5 个单元格，第 3 个带 `AlignCenter`

## 实现要点

- 两侧行高必须严格一致否则会逐行错位，因此行盒统一 `line-height: 16px` + 固定 `height`，且**不要**给代码单元格加 `word-break` / `overflow-wrap` —— 允许任意断词会改变列宽并压扁长行。
- 空行在原报告里写作 `&nbsp;`，判断「该侧无内容」时要先剥离标签与实体。
- 复用原表格 HTML 以保留语法高亮配色，行号单独生成以保证左右对齐。

## 文件结构

```text
diff-center-nav/
  manifest.json   清单（MV3）
  background.js   点扩展图标时的兜底注入
  diff-core.js    报告表格识别与行数据抽取
  content.js      双栏渲染、联动滚动、导航、放大对话框
  content.css     双栏布局与高亮样式
  README.md
```
