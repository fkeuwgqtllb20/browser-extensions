# 比对报告差异居中导航

在 Beyond Compare 导出的 HTML 比对报告（`*.html`）中识别左右两侧差异，自动把当前差异滚动到视口中央，并提供上一个/下一个差异跳转。

## 功能

- **差异识别**：读取报告中的 `table.fc`，通过行样式（`TextItemSame` / `TextItemSigMod` / `TextItemInsigMod` / `TextItem*Add` / `TextItem*Del`）和中间的 `+`、`+-` 标记判断差异行。
- **差异块合并**：连续的差异行合并为一处「差异块」，一次跳转覆盖整段修改，不会逐行卡顿。
- **居中显示**：跳转后把整个差异块垂直居中；差异块高于视口 80% 时改为贴到视口顶部，避免看不到开头。
- **上一个 / 下一个**：顶部居中工具条或键盘 `Alt+↑` / `Alt+↓` 循环跳转，`Alt+Home` 回到第一处。
- **当前差异高亮**：整段差异块绘制为一个连续外框（首行上边、末行下边、左右各一条），块内统一浅黄底色，不会逐行套方框；显著差异在左侧加红色细线，非显著差异为灰色。
- **仅看差异**：可折叠连续 3 行以上的相同内容，在差异块之间插入「⋯ 已折叠 N 行」占位条，点击即可展开；折叠状态记录在 `localStorage`。折叠前会先冻结列宽，避免隐藏行后表格重排列宽。
- **双击放大对照**：双击任意差异行（或点工具条 `⤢`）弹出放大对话框，上下结构分别展示左右两侧完整内容，两侧横向滚动联动 —— 滚任意一边另一边跟着滚。行号、缩进原样保留，超长行可横向滚动查看。

工具条固定在页面顶部水平居中，不遮挡左右两侧的代码内容。

## 安装

1. 打开 Chrome：`chrome://extensions/`
2. 打开右上角「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择本目录 `extensions/diff-center-nav`。
4. 打开比对报告 HTML 即可：

   - 用 `chrome://extensions/` → 该扩展「详情」→ 打开「允许访问文件网址」，刷新报告页后工具条自动出现。
   - 未开启文件访问权限时，直接点击工具栏的扩展图标即可手动注入当前标签页。

## 使用

右上角 / 顶部居中的悬浮工具条提供全部操作：

| 操作 | 方式 |
| --- | --- |
| 下一个差异 | 工具条 `▶` 或 `Alt+↓` |
| 上一个差异 | 工具条 `◀` 或 `Alt+↑` |
| 第一处差异 | `Alt+Home` |
| 仅看差异（折叠相同内容） | 工具条「仅看差异」按钮，再次点击取消 |
| 重新扫描差异 | 工具条 `⟳` |
| 放大对照当前差异 | 双击任意差异行，或点工具条 `⤢` |
| 收起 / 展开 | 工具条 `–` 收起为「差异 n/m」胶囊，点击胶囊恢复 |

对话框内按 `Esc` 关闭，`Alt+↑` / `Alt+↓` 可直接切换到上/下一处差异。

## 适配范围

默认在 `file:///*` 与 `http://localhost/*` 下自动生效。如果报告放在内网服务器或其他域名，在 `manifest.json` 的 `content_scripts[0].matches` 中追加对应匹配规则后重新加载扩展；临时使用可直接点扩展图标注入。

只对同时满足以下条件的表格生效，普通网页不受影响：

- 表格带 `class="fc"`
- 至少 3 行带 `Section*` / `Subsection*` 类名
- 每行 5 个单元格，第 3 个单元格带 `AlignCenter`

## 文件结构

```text
diff-center-nav/
  manifest.json   清单（MV3）
  background.js   点扩展图标时的兜底注入
  diff-core.js    报告表格与差异块的识别
  content.js      面板交互、居中滚动、折叠
  content.css     面板样式与差异高亮
  README.md
```
