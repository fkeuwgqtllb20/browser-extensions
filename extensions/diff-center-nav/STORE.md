## 简短说明（132 字符以内）

```
把 Beyond Compare 导出的 HTML 比对报告重排为左右双栏对照视图，两侧联动滚动，支持差异跳转、仅看差异与放大对照。
```

当前长度 53 字，远低于上限。

## 详细说明

```
【解决的问题】
Beyond Compare 导出的 HTML 比对报告是一张超宽表格，长代码行会把表格撑到上万像素
（实测某报告总宽 16442px，左右两列各 8171px）。在普通显示器上永远只能看到一侧，
必须整页横向拖动，来回对照非常低效。

【本扩展的做法】
把报告数据抽出后重新排版为左右双栏：左右各占一半视口宽度，各自横向滚动且位置联动，
因此两侧始终同时可见，逐行严格对齐。

【功能】
· 左右双栏对照，中间分隔条可拖动调整比例
· 滚动联动：滚任意一侧，另一侧横向与纵向同步
· 差异识别：连续差异行合并为一处「差异块」
· 一键跳转：◀ / ▶ 或 Alt+↑ / Alt+↓，Alt+Home 回第一处
· 当前差异整块高亮，跳转时自动垂直居中
· 仅看差异：折叠连续 3 行以上的相同内容，两侧同步折叠
· 放大对照：双击差异行弹出上下结构对话框，长行横向滚动
· 保留原报告的语法高亮配色

【使用方法】
1. 在 chrome://extensions/ 打开本扩展的「允许访问文件网址」
2. 用 Chrome 打开 .html 比对报告，页面自动变为双栏视图
3. 若未开文件访问权限，点击工具栏图标即可手动注入当前页

【适用范围】
仅对同时满足以下条件的表格生效，普通网页完全不受影响：
· 表格带 class="fc"
· 至少 3 行带 Section* / Subsection* 类名
· 每行 5 个单元格，第 3 个带 AlignCenter

【隐私】
不收集任何数据，不联网，不需要任何远程权限。
```

## 权限说明（提交时需逐项填写理由）

| 权限 | 用途 | 用户可见的影响 |
| --- | --- | --- |
| `scripting` | 用户点击扩展图标时，把双栏脚本注入当前标签页 | 仅在用户主动点击时触发 |
| `activeTab` | 同上，仅在用户点击图标后临时获取当前页访问权 | 不常驻，不读取其他标签页 |

**不申请**：`storage`、`tabs`（读取 URL/标题）、`<all_urls>`、任何远程主机权限。

数据都在浏览器本地处理：折叠状态用 `localStorage` 存在报告页面自身，无外部请求。

## 上传方式

1. 把 `diff-center-nav/` 打包成 zip（**不要包含** `store/`、`README.md` 和示例 `*.html`）
2. 打开 https://chrome.google.com/webstore/devconsole
3. 支付一次性开发者注册费（个人约 5 美元）
4. 新建项目 → 上传 zip → 填写上面各节内容 → 提交审核

打包命令（在扩展目录的上一级执行）：

```bash
cd extensions
zip -r diff-center-nav.zip diff-center-nav \
  -x 'diff-center-nav/store/*' \
  -x 'diff-center-nav/README.md' \
  -x 'diff-center-nav/*.html' \
  -x 'diff-center-nav/store.md'
```

## 审核注意事项

- 扩展只对 `file://` 生效，审核员可能不会主动打开本地文件。**详细说明里务必写清测试步骤**，最好附上一个示例报告文件的链接，方便审核复现。
- `activeTab` + `scripting` 属于低风险权限，但需在权限理由里说明「仅在用户点击时注入」。
- 不申请主机权限、不联网，通常能显著缩短审核时间。
