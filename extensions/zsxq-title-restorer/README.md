# 知识星球完整标题恢复

在知识星球课程目录中恢复被 `...` 截断的课程标题，并复制整理后的标题列表。

## 原理

知识星球课程目录中的一部分 `a.link-of-topic` 标题及 `title` 属性本身已被截断，无法只靠 CSS 或 URL 解码恢复。扩展会：

1. 扫描当前页面的所有知识星球课程链接；
2. 创建 **一个不抢焦点的后台标签页**；
3. 在该标签页依次加载课程详情，读取详情页的完整浏览器标题；
4. 回填当前目录页的标题；
5. 自动关闭后台标签页。之后可点击“复制当前标题”。

不会点击当前页面中的课程链接，也不会为每条课程创建新标签页。

## 安装

1. 在 Chrome 打开 `chrome://extensions/`。
2. 打开右上角的“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本目录：`D:\browser-extensions\extensions\zsxq-title-restorer`。
5. 刷新 `https://wx.zsxq.com/` 中的课程目录页。

## 使用

1. 打开包含课程目录的知识星球页面。
2. 右下角会出现“完整课程标题”面板。
3. 点击“恢复完整标题”。
4. 完成后点击“复制当前标题”，再粘贴进文件夹脚本。

## 说明

- 处理时会出现一个后台标签页，但它不会抢占当前页面，并会在完成或停止后自动关闭。
- 请保持知识星球登录状态。
- 如中途刷新课程页，扩展仍可能继续处理；点击“停止”或重新加载扩展可终止任务。
