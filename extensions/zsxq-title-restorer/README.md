# 知识星球完整标题恢复

在知识星球课程目录中恢复被 `...` 截断的课程标题，并复制带学习顺序编号的标题列表。

## 原理

知识星球课程目录中的一部分 `a.link-of-topic` 标题及 `title` 属性本身已被截断，无法只靠 CSS 或 URL 解码恢复。扩展会：

1. 扫描当前页面的所有知识星球课程链接；
2. 创建 **一个不抢焦点的后台标签页**；
3. 在该标签页依次加载课程详情，读取详情页的完整浏览器标题；
4. 回填当前目录页的标题；
5. 自动关闭后台标签页。之后可点击“复制标题（含序号）”。

复制时会读取课程链接前面的目录序号（例如 `- 16：`），输出为：

```text
- 16： 《AI MCP Gateway》第1-4节：升级网关库表
```

序号来自链接前面的目录文本，而不是标题内容。检测到 `- N：` 的行会加上 `- N：` 前缀；没有序号的课程标题原样保留，避免漏掉目录项。未检测到序号时，仍按原来的规则复制全部知识星球链接。

不会点击当前页面中的课程链接，也不会为每条课程创建新标签页。

## 提取课程视频 m3u8

扩展还支持从课程标题对应的两层知识星球页面提取视频播放地址：

1. 在包含第一层课程链接的目录页打开面板；也可以在“标题列表（可选）”中粘贴标题，每行一个，支持 `- 2： 标题` 格式。
2. 点击“提取 m3u8”。扩展会在一个后台标签页中依次打开第一层主题页、跟随“课程视频”链接进入第二层主题页。
3. 在第二层页面读取 `video[data-src]` 中的 m3u8 地址。
4. 完成后点击“复制 m3u8 结果”。复制内容为“标题 + Tab + m3u8 地址”，便于保存和后续处理。

如果只粘贴标题，扩展会在当前页面的第一层链接中进行匹配；匹配不到的标题会在状态中提示。m3u8 地址通常带有时效 token，请提取后及时保存并避免公开分享。

## 安装

1. 在 Chrome 打开 `chrome://extensions/`。
2. 打开右上角的“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本目录：`D:\browser-extensions\extensions\zsxq-title-restorer`。
5. 刷新 `https://wx.zsxq.com/` 中的课程目录页。

## 使用

1. 打开包含课程目录的知识星球页面。
2. 右下角会出现“完整课程标题”面板。
3. 点击“恢复完整标题”。
4. 完成后点击“复制标题（含序号）”，再粘贴进文件夹脚本。

## 说明

- 处理时会出现一个后台标签页，但它不会抢占当前页面，并会在完成或停止后自动关闭。
- 请保持知识星球登录状态。
- 如中途刷新课程页，扩展仍可能继续处理；点击“停止”或重新加载扩展可终止任务。
