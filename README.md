# 浏览器扩展集合

集中存放个人浏览器扩展，每个扩展独立放在 `extensions/` 下的一个子目录中。

## 扩展列表

| 扩展 | 说明 | 目录 |
| --- | --- | --- |
| 知识星球可折叠目录 | 在知识星球文章页自动生成可折叠目录，支持点击跳转和当前章节高亮。 | `extensions/zsxq-collapsible-toc/` |
| 知识星球完整标题恢复 | 恢复被 `...` 截断的课程标题，保留学习序号，并支持跨两层页面提取课程视频 m3u8。 | `extensions/zsxq-title-restorer/` |
| 比对报告差异居中导航 | 把 Beyond Compare 导出的 HTML 比对报告重排为左右双栏对照视图，两侧联动滚动，支持差异跳转、仅看差异与放大对照。 | `extensions/diff-center-nav/` |

## 安装方式

1. 打开 Chrome：`chrome://extensions/`
2. 打开右上角「开发者模式」。
3. 点击「加载已解压的扩展程序」。
4. 选择需要安装的扩展子目录，例如：`D:\browser-extensions\extensions\zsxq-title-restorer`。
5. 如已加载过该扩展，修改文件后点击扩展卡片上的“重新加载”。
6. 刷新目标网页后使用。

## 知识星球完整标题恢复

适用于 `https://wx.zsxq.com/` 内包含课程目录的页面。

1. 保持知识星球已登录并打开课程目录页。
2. 页面右下角会显示“完整课程标题”面板。
3. 点击“恢复完整标题”。
   - `title` 属性完整的课程会立即恢复，不访问详情页。
   - `title` 本身含 `...` 的课程，会在**一个不抢焦点的后台标签页**中依次读取详情页标题。
   - 全部处理完毕后，后台标签页会自动关闭。
4. 点击“复制标题（含序号）”，将课程目录（含学习顺序序号）的标题列表复制到剪贴板。

复制功能会识别课程链接前面的目录文本（如 `- 16：` 或无编号的 `- `），而不是从标题里的章节号推断；有序号的行会带上前缀，没有序号的标题原样保留。未检测到序号时则继续复制全部链接，保持原有兼容行为。

### 课程视频 m3u8 提取

在面板中粘贴标题列表（可选）并点击“提取 m3u8”后，扩展会依次打开第一层课程主题页和“课程视频”指向的第二层主题页，从第二层 `video[data-src]` 读取 m3u8。点击“复制 m3u8 结果”可复制“标题 + Tab + 地址”；未匹配的标题和失败项会显示在状态中。m3u8 地址通常带有时效 token，请及时保存。

标题会在恢复、匹配和复制前自动还原 HTML 实体（例如 `&amp;`），下载器也会用还原后的标题创建目录和文件名；实体处理不会改写 m3u8 地址。

该扩展不使用嵌入式 iframe，以避免知识星球页面可能出现的 `login id is invalid` 错误。

## 比对报告差异居中导航

适用于 Beyond Compare 导出的 HTML 比对报告，直接用 Chrome 打开即可。

原报告是「单张大表格 + 内容不换行」，长代码行会把表格撑到上万像素宽（实测某报告总宽 16442px，左右两列各 8171px），普通显示器上永远只能看到一侧。扩展把数据重新排版成**左右双栏对照视图**，两侧始终同时可见。

1. 首次使用在 `chrome://extensions/` → 该扩展「详情」中打开「允许访问文件网址」；未开启时点一下工具栏扩展图标即可手动注入当前标签页。
2. 报告会被重排为左右双栏：左栏红标、右栏蓝标，标题栏显示两边文件名；中间分隔条可拖动调整比例。
3. 滚轮或拖动任一侧，另一侧横向与纵向同步滚动，逐行始终对齐；长代码行不换行，各自横向滚动。
4. 点击 `◀` / `▶` 或按 `Alt+↓` / `Alt+↑` 循环跳转，`Alt+Home` 回到第一处；整段差异垂直居中，超过视口 80% 高度时贴顶。
5. 当前差异块绘制为一个连续外框（首行上边、末行下边、左右各一条），块内统一浅黄底色，不会逐行套框。
6. 点击「仅看差异」可折叠连续 3 行以上的相同内容，左右两侧同步折叠为「⋯ 已折叠 N 行」占位条。
7. 双击任意差异行（或点工具条 `⤢`）弹出放大对照对话框：上下结构分别展示左右两侧完整内容，两侧横向滚动联动；`Esc` 关闭。

详细的适配范围与文件说明见 `extensions/diff-center-nav/README.md`。
